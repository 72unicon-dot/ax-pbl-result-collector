# AX-PBL 결과수집 앱 개발 명세

## 목적
48개 과제별 현업 사용 결과, 업무 규칙, 데이터 연계정보를 동일 양식으로 수집하여 통합 MVP 후보를 선정한다.

## 현재 업무
각 과제별 실제 사용 결과와 업무 규칙이 서로 다른 문서·대화·시트에 분산되어 있어 비교가 어렵다.

## 문제점
- 과제명·부서·작성자·오너 정보 누락
- 정량효과와 정성효과가 분리되지 않음
- 필수값·계산식·승인규칙·예외처리 등 개발에 필요한 업무 규칙 부족
- 통합 MVP 후보 선정을 위한 공통 판정 기준 부재

## 개선 목표
- 누구나 접속해 표준 Form으로 작성
- Supabase를 운영 원장으로 저장
- Google Sheets에 실시간 취합하여 워크숍/멘토링에서 검토
- 향후 통합 업무지원 플랫폼의 요구사항 DB로 전환

## 필요 데이터
- 과제 마스터: 통합ID, 과제명, 유형, 점수, 등급, 권장단계, 부서
- 제출 데이터: 과제개요, 사용결과, 업무규칙, 데이터연계, 재사용성, 확인요청, 최종판정

## 담당자
- Process Owner: 과제별 업무 범위와 최종 판정 확인
- Data Owner: 원천 데이터와 권한 확인
- Technical Owner: Supabase/Vercel/Google Sheets 연동 운영
- 현업 작성자: 실제 사용 결과 입력

## 예상 효과
- 48개 과제 비교 가능
- 통합 MVP 후보 선정 근거 확보
- Codex 개발명세로 전환 가능한 업무규칙 축적
- Google Sheets 기반 현업 리뷰 속도 향상

## 검증 기준
- 정상 제출 시 Supabase 저장
- Google Sheets Webhook 설정 시 행 추가
- 필수값 누락 시 저장 거부
- 과제 마스터 48개 선택 가능
- 관리자 화면에서 제출 목록과 KPI 확인
